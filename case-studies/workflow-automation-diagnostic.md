# Workflow and API Automation Diagnostic

## Offer

A focused diagnostic for an SME whose work is slowed by spreadsheets, duplicated data entry, manual approvals, disconnected reports or fragile hand-offs.

## What the client receives

- 60–90 minute discovery session
- Current workflow map
- Waste, risk and control-point review
- Prioritised next slice
- Implementation estimate and suggested acceptance criteria

## Commercial starting point

**RM350 diagnostic**. Any implementation work is quoted separately after the workflow and scope are understood.

## Follow-on options

- Fixed-scope implementation sprint
- Dashboard or API integration
- Automation handover and documentation
- Optional support arrangement
