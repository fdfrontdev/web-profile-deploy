# Web Profile — Mohamad Firdaus

Single-page personal web profile for **Mohamad Firdaus** — freelance software engineer.

Built as a single `index.html` with inline CSS and JavaScript. Zero build tools, zero external dependencies except Google Fonts (Inter).

## Deploy

This is a static site. Deploy anywhere that serves HTML:

| Platform | Instructions |
|----------|-------------|
| **GitHub Pages** | Push to a repo, enable Pages from the branch |
| **Netlify** | Drag `index.html` onto Netlify Drop |
| **Vercel** | `vercel --prod` |
| **Any static host** | Copy `index.html` to your web root |

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid)
- Vanilla JavaScript (IntersectionObserver)
- Google Fonts: Inter

## Sections

- **Hero** — Name, tagline, location, CTA
- **About** — Bio + stats cards
- **Projects** — featured projects with verified evidence and live links where available
- **Services** — 4 service offerings
- **Skills** — Tech stack badges by category
- **Contact** — Email, LinkedIn, GitHub links
- **Footer**

## Design

- Dark theme (`#0a0a0a` background)
- Green accent (`#22c55e`) used sparingly for impact
- Glass-effect fixed navigation
- Smooth scroll via CSS `scroll-behavior: smooth`
- Fade-in animations via IntersectionObserver
- Fully responsive (320px – 1440px)
